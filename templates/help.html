전체 업무 흐름

배송비 단가 산정은 아래 순서로 진행합니다. 최초 1회 마스터 데이터를 세팅한 후, 이후에는 ③~⑤만 반복하면 됩니다.

1
마스터 데이터 등록 차량 단가 · 이고비 · 거리별 단가표 · 자사 센터 · (필요 시) 배송 거점 매핑을 먼저 등록합니다.
2
고객사 등록 및 기준 데이터 입력 고객사를 등록하고 상품(PLT 환산 기준)·점포 마스터를 업로드합니다.
3
출고 내역 업로드 배송비 산정 화면에서 엑셀 형식의 출고 내역 파일을 업로드합니다.
4
배송비 산정 실행 직송/공동배송 분류 → 이고비 + 변동용차비 자동 계산이 이루어집니다.
5
결과 확인 및 내보내기 고객사 상세 분석에서 물류비를 검토하고 엑셀로 내보내 견적서 작성에 활용합니다.
Tip
직송/공동배송 분류 기준(PLT 임계값)은 전역 설정이 아니라 고객사별로 개별 설정합니다 — 고객사 상세 분석 화면의 "직송 물류비" 카드에서 조정합니다.

  • 박스당 배송단가: 최소 / 최대 / 절충(최소 이고비 + 최대 변동용차) 3가지 값 동시 표시 — 가장 중요한 견적 기준 수치
  • 총 물류비 카드 아래로 화살표를 따라 직송/공동배송 → 이고비/변동용차 순으로 비용이 어떻게 갈라지는지 시각적으로 확인
  • 이고비 카드에 11톤트럭 평균 용적률 표시 — 실제 트럭 대수가 확정되는 최대 기준으로 계산
  • 시너지율 카드에 % 입력 시 절충/최대 단가에 실시간 반영 (절충 값은 변동용차에만 할인 적용)
  • 이고비·변동용차 카드 클릭 → 거점별 상세 내역 모달(일자별 PLT·트럭대수·비용)
  • "직송 물류비" 카드에서 직송 전환 PLT 기준을 고객사별로 개별 조정 가능 (전역 설정 아님)
  • 하단 차트: 일별·월별·요일별 출고량 추이, 직송시 차량투입현황, 배송 유형 비율(직송/공동배송 % 포함)
  • 우측 상단 엑셀 내보내기 · 배송망 지도 바로가기
Tip
변동용차비 카드의 일평균은 지도 시뮬레이션과 동일한 알고리즘(planRoutes)으로 계산됩니다. 카드 총합 = 일평균 × 전체 영업일수입니다 (공동배송 발생일이 아닌 전체 출고일 기준).

출고 내역 엑셀을 업로드하고 배송비를 자동 계산합니다. 고객사 관리 페이지의 배송비 산정 단계에서 진행합니다.

{% if screenshots.get('calculate') %} {% else %}
스크린샷 미생성
{% endif %}
  • 출고 내역 엑셀 업로드 → 자동으로 배치(Batch) 생성. 필수 컬럼은 배송처(코드/명)와 박스수 — PLT 컬럼이 없으면 상품 마스터 기준으로 자동 환산
  • 별도 카드로 자사 배송지시서 업로드 지원 — 공동배송 가능 지역을 분석하는 시너지 분석용 데이터
  • 산정 실행 시 산정명 · 메인센터(필수) · 사용할 출고내역 배치를 선택
  • 산정 실행 클릭 → PLT 기준으로 직송/공동배송 분류 후 비용 계산
  • 직송: 차량 단가 마스터 기반으로 최적 차종 선택 / 공동배송: 이고비 + 변동용차비 자동 산출
  • 업로드된 배치 목록에서 개별 삭제 가능
Tip
현재 적용 중인 직송 전환 PLT 기준값이 안내 박스에 표시됩니다. 값을 바꾸려면 고객사 상세 분석 화면의 "직송 물류비" 카드를 이용하세요.
